# Breakout Clone

**[中文]**
這是一個使用 Python 和 Pygame 函式庫開發的經典打磚塊 (Breakout) 遊戲。玩家需要透過移動底部的擋板來反彈小球，目標是擊碎畫面上方所有的磚塊。

**[English]**
This is a classic Breakout game developed using Python and the Pygame library. Players control the paddle at the bottom by moving it to bounce the ball, with the goal of breaking all the bricks at the top of the screen.

---

## 遊戲特色 / Features

**[中文]**
*   **經典街機體驗**：還原經典打磚塊遊戲的核心玩法，包含精準的邊界與磚塊碰撞檢測。
*   **滑鼠直覺控制**：擋板會跟隨滑鼠游標移動，提供流暢且直覺的操控手感。
*   **完整的遊戲生命週期**：包含開始畫面 (Start Menu)、遊戲進行 (Gameplay)、勝利 (Win) 與失敗 (Game Over) 狀態切換。
*   **互動式 UI 按鈕**：內建自定義的互動按鈕（Start, Restart, Leave），支援滑鼠點擊操作。

**[English]**
*   **Classic Arcade Experience**: Replicates the core gameplay of the classic Breakout game, including precise boundary and brick collision detection.
*   **Intuitive Mouse Control**: The paddle smoothly follows the mouse cursor, providing intuitive handling.
*   **Complete Game Lifecycle**: Includes seamless state transitions between the Start Menu, Gameplay, Win, and Game Over screens.
*   **Interactive UI Buttons**: Built-in custom interactive buttons (Start, Restart, Leave) with mouse click support.

### 開發環境安裝與執行指令 / Installation & Execution Commands

**[中文]**
1. **複製儲存庫到本地端** (請將連結替換為你的 GitHub URL)：
   ```bash
   git clone https://github.com/HiTea-1089/Bricks-Breaking.git
   cd Bricks-Breaking
   ```
2. **安裝依賴套件**：
   ```bash
   pip install pygame
   ```
3. **從原始碼啟動遊戲**：
   ```bash
   python BreakoutcloneAI.py
   ```

## 操作說明 / How to Play

**[中文]**
*   **移動擋板**：在遊戲視窗內左右移動 **滑鼠**。
*   **點擊按鈕**：使用 **滑鼠左鍵** 點擊介面上的按鈕進行遊戲開始、重新啟動或離開遊戲。

**[English]**
*   **Move the Paddle**: Move the **mouse** left and right within the game window.
*   **Click Buttons**: Use the **Left Mouse Button** to click on-screen buttons to start, restart, or leave the game.
